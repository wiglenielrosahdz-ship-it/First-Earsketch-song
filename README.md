# First-Earsketch-song
This is code that I had made for a song within Earsketch's Digital Audio Workstation.

----------------------How to use---------------------------------

1. Download or copy the code from here.
   
2. Go to Earsketch.gatech.edu.
   
3. Select create a new script, and ensure that the coding language is JavaScript.
   
4. Copy the code into the file, and select run inside of the editor. (This will load all the necessary assets into the DAW)
   
5. Press play near the top of the webpage, and listen to the sounds a 16 year old made.
